# Gurnoor — Developer Portfolio

A motion-led, responsive portfolio showcasing six selected projects across aviation, commerce, coaching, and learning.

## Stack
- React + TypeScript
- Vite
- Custom CSS motion and responsive layouts
- IntersectionObserver scroll reveals, animated project artwork, keyboard-accessible project details, reduced-motion support

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy with Vercel
Import this repository into Vercel with the Vite framework preset. The build command is `npm run build`; the output directory is `dist`.

Or from a terminal:
```bash
npm install -g vercel
vercel
vercel --prod
```

## Portfolio projects
